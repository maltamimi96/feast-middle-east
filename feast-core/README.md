# Feast Core

Project-specific WordPress companion plugin for Feast in the Middle East.

## Requirements

- WordPress 6.0+
- PHP 7.4+
- Elementor Free for visual widgets
- The Feast in the Middle East theme for the existing CMS data and enquiry form

## Visual editing

The plugin adds these Elementor widgets:

- Feast Hero Slider
- Feast CMS Collection (dishes, catering packages, gallery, FAQs)
- Feast Catering Enquiry

It also adds **Feast CMS → Visual Layouts**, where ordinary Elementor pages can be assigned as the global header and footer without Elementor Pro.
